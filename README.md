# RunWay

러닝 기록과 워치 데이터를 기반으로 개인에게 맞는 코스와 페이스를 제안하고, 개인·그룹 러닝 중 실시간 페이스 조정을 돕는 **AI 러닝 코치 서비스**

> 기획 확정 전 초안

## 1차 MVP 기능

| 기능 | 설명 |
| --- | --- |
| 👤 러닝 프로필 및 목표 설정 | 러닝 수준, 목표 거리·완주 시간, 선호 환경 설정 |
| 🗺️ AI 러닝 코스 추천·생성 | 위치, 목표 거리, 선호 환경, 경사도, 안전 요소를 고려한 코스 추천·생성 |
| 🏃 AI 페이스 분석·예측 | 목표와 과거 기록 기반 구간별 목표 페이스 계산 및 목표 달성 가능성 예측 |
| ❤️ 실시간 운동 상태 분석 | 심박수·페이스·케이던스 변화로 운동 부담, 오버페이스, 이상 패턴 감지 |
| 🎵 개인화 BPM 리듬 가이드 | 목표 페이스를 개인별 BPM으로 변환하고 실제 반응에 따라 보정 |
| 📊 러닝 기록 분석 | GPS 경로, 페이스, 심박수 등 기록 및 구간별 변화·목표 달성 분석 |
| 👥 그룹런 및 AI 그룹 페이스 분석 | 그룹런 생성·참여, 진행 현황 공유, 공동 페이스 계산 및 참가자별 BPM 제공 |
| ⌚ Galaxy Watch 연동 | 실시간 운동 데이터 수집, 러닝 시작·종료 제어, BPM·페이스·그룹 알림 |
| 🤝 러닝 메이트·크루 모집 | 페이스·수준·목표가 비슷한 러닝 메이트 매칭 및 크루 모집 |
| 💬 러닝 커뮤니티 | 러닝 정보, 추천 코스, 기록 공유 |

## 폴더 구조

```
.
├── backend/    # 백엔드 서버
├── frontend/   # 프론트엔드
├── ai/         # AI 모델·파이프라인
├── infra/      # 배포·인프라 설정
├── docs/       # 기획·설계 문서
└── exec/       # 포팅 매뉴얼
```

## Jira 업무 자동화

자연어로 AI에게 업무 등록을 요청하면 내용을 제안하고, 사용자 확인 후 Jira에 생성한다.
개발자별 최초 설정과 사용 방법은 [Jira 자동화 가이드](docs/jira-automation.md)를 참고한다.
AI의 Jira·브랜치·MR 작업 규칙은 [AGENTS.md](AGENTS.md)에 정리되어 있다.
