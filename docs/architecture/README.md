# 아키텍처 문서

시스템 구성과 데이터 모델처럼 여러 구현 영역이 함께 참조하는 설계 문서를 둔다. 기술 선택의 이유와 변경 이력은 이 폴더에 복제하지 않고 [ADR](../adr/README.md)에서 관리한다.

## 문서 위치

- `system-overview.md`: 서비스 경계와 주요 데이터 흐름이 확정되면 추가한다.
- [`data-model/`](data-model/): ERD 스키마 원본과 데이터 모델 설명을 관리한다.

데이터 모델은 `data-model/schema.sql`을 기준으로 확인한다. 존재하지 않는 시스템 설계를 추정해 빈 계약을 만들지 않으며, 확정 자료가 추가되면 이 목록과 최상위 [문서 안내](../README.md)를 함께 갱신한다.
