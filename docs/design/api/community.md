## CMT01 게시물 작성

`POST` `/api/v1/posts`

| 항목 | 값 |
|---|---|
| 단계 | 1차 MVP |
| 인증 | 회원 |
| 관련 요구사항 | COM-001~004 |
| 관련 화면 | 7.3 글쓰기, 4.5 '기록 공유', 6.7 '커뮤니티에 공유' (화면 설계 v10) |
| 미정 사항 | 있음 |
| 비고 | API 요청/응답 필드와 값 제한은 검토용 제안 |

### 설명

본인 러닝 기록의 표시용 결과를 게시물로 공유한다. 원본 기록 소유권을 확인하며 게시물 공개 범위는 계정 정책을 따른다.

### 인증 및 권한

- 로그인 사용자 본인 또는 서비스 리소스 접근 권한 검사.
- 건강정보·실시간 위치·타인 기록 조회 시 동의 상태 및 공개 범위가 우선한다.

### Path Parameters

없음

### Query Parameters

없음

### Request Body

| 필드 | 타입 | 필수 | 설명 |
|---|---|:---:|---|
| `postType` | string (제안) | O | RUNNING_RECORD(기록 공유) |
| `title` | string / object (확인 필요) | X | ERD 및 화면 요구사항을 기준으로 확정 필요 |
| `body` | string / object (확인 필요) | O | ERD 및 화면 요구사항을 기준으로 확정 필요 |
| `sessionId` | string (UUID) | O | 본인의 공유할 완료 러닝 세션 UUID |
| `courseId` | string (UUID) | X | 선택한 코스 식별자. 개인·그룹 자유러닝은 null/생략 가능 |
| `imageId` | string (UUID) | X | 결과 화면 사진([F01](files.md#f01-이미지-업로드)). 서버 생성 시 생략 |

```json
{
  "postType": "RUNNING_RECORD",
  "sessionId": "00000000-0000-4000-8000-000000000001",
  "body": "오늘 5km를 달렸어요."
}
```

### Response

{}

| 필드 | 타입 | 필수 | 설명 |
|---|---|:---:|---|
| `id` | string (UUID) | X | ERD 및 화면 요구사항을 기준으로 확정 필요 |
| `postType` | string (제안) | X | RUNNING_RECORD(기록 공유) |
| `title` | string / object (확인 필요) | X | ERD 및 화면 요구사항을 기준으로 확정 필요 |
| `body` | string / object (확인 필요) | X | ERD 및 화면 요구사항을 기준으로 확정 필요 |
| `authorId` | string (UUID) | X | ERD 및 화면 요구사항을 기준으로 확정 필요 |
| `sessionId` | string (UUID) | O | 본인의 공유할 완료 러닝 세션 UUID |
| `courseId` | string (UUID) | X | 선택한 코스 식별자. 개인·그룹 자유러닝은 null/생략 가능 |
| `createdAt` | string (ISO 8601) | X | ERD 및 화면 요구사항을 기준으로 확정 필요 |

### 오류 응답

- `403 RESOURCE_NOT_OWNED`
- `422 INVALID_POST`
- 공통 인증 오류 `401 UNAUTHORIZED`, 권한 오류 `403 FORBIDDEN`, 요청 형식 오류 `400 VALIDATION_ERROR` (해당 시).

### 처리 규칙

- 게시물별·연결 러닝 기록별 공개 설정은 없다. 공개 계정의 게시물은 전체에, 비공개 계정은 본인·승인된 팔로워에게만 제공한다. 대기 요청자는 접근할 수 없다.
- 목록·상세·연결 이미지·댓글·반응 등 관련 접근에서도 작성자 계정 정책을 검증한다. 원본 H02 조회 권한을 타인에게 부여하지 않고 공유 표시용 요약·경로 그림만 제공한다.

- 새 글은 4.5 러닝 결과·6.7 그룹런 결과의 '기록 공유'에서만 쓴다(postType=RUNNING_RECORD, sessionId 필수).
- '코스도 함께 공유'를 켜면 세션의 courseId를 함께 보낸다.
- 본인 러닝 기록의 표시용 결과를 게시물로 공유한다. 원본 기록 소유권을 확인하며 게시물 공개 범위는 계정 정책을 따른다.
- 사용자 소유권·그룹 참가 권한·상태 전이·재요청 여부를 검증한다(적용 범위는 API별로 결정).
- 예시는 **명세 구조를 보여주는 가상 값**이며, 확정되지 않은 제한·동기화 주기·AI 호출 주기를 의미하지 않는다.

### 상태값

- 게시물별 공개 설정 없음. 작성자 계정 정책과 게시물 삭제 상태를 적용한다.

### 미정 사항

- [ ] 결과 사진을 클라이언트 캡처 업로드로 받을지 서버에서 생성할지
- [ ] 요청·응답의 세부 필드 타입, 허용 범위, nullable 규칙 및 실제 JSON 구조 검토
- [ ] HTTP 성공 코드 및 각 예외의 오류 코드 최종 확정
- [ ] 접근 권한과 데이터 정합성의 구체적인 처리 조건 확정
