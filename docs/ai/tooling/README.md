# 개발용 AI 도구 조사

Context7, Superpowers와 Maestro MCP의 조사 자료를 도구별 문서로 관리한다. 문서를 추가할 때는 다음 내용을 구분한다.

- 도구의 역할과 적용 대상
- 설치 전제조건과 지원 환경
- 저장소에 필요한 설정과 프로젝트 구조 의존성
- 사용할 수 있는 기본 기능과 명시적인 제외 범위
- 확인한 버전·날짜·공식 출처
- 실제 설치 및 검증 여부

예정 문서명은 `context7.md`, `superpowers.md`, `maestro-mcp.md`이다. 조사 전에는 설치 완료나 적용 확정으로 표시하지 않는다.
