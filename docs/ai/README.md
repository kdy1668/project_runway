# 개발용 AI 문서

개발과 검증을 돕는 AI 도구의 조사 결과, 적용 조건과 검증 기록을 관리한다. 이 영역은 RunWay 서비스 내부의 AI 모델·에이전트·오케스트레이션 설계와 분리한다.

## 현재 확정된 범위

- Context7, Superpowers, Maestro MCP를 개발 및 검증 도구로 활용할 계획이다.
- 기존 FEELM 프로젝트의 AI 관련 Markdown 문서를 참고해 RunWay의 AI 작업 규칙을 관리한다.
- 실제 공통 작업 규칙과 인증정보 보호 기준은 저장소 루트의 [`AGENTS.md`](../../AGENTS.md)를 기준으로 한다.

## 아직 확정하지 않는 항목

- 도구별 테스트 범위와 통과 기준
- 다른 AI 도구와의 조합 및 오케스트레이션 방식
- RunWay 서비스 내부 AI 모델·에이전트 구성과 프레임워크
- 개발용 Subagents의 역할과 운영 방식
- Skills, Hooks, CI의 구체적인 구성
- 테스트 및 배포 아키텍처

위 항목은 조사·비교 결과와 선행 결정을 바탕으로 별도 업무에서 확정한다. 합의 전에는 설정 파일이나 실행 구조를 만들지 않는다.

## 하위 문서
